# Photos

Drop your images here using these exact file names. Until a file exists, the site shows a soft placeholder instead, so nothing ever looks broken.

| File | Where it shows | Shape |
|---|---|---|
| hero.jpg | Main photo at the top | Portrait (4:5) |
| hero-2.jpg | Small overlapping photo | Square |
| family.jpg, newborn.jpg, children.jpg, seasonal.jpg, maternity.jpg, events.jpg | Session cards | Landscape (4:3) |
| gallery-1.jpg … gallery-6.jpg | "A little look" gallery | Any; 1 and 4 show larger |
| about.jpg | About section (a photo of you) | Portrait (4:5) |
| og-image.jpg | Preview when the link is shared on WhatsApp/Facebook | 1200 × 630 |

Tips:
- Export at around 1600px on the long edge, JPG quality ~75–80. Aim for under 300 KB each — page speed matters for Google ranking on mobile.
- Only use images of children where you hold written permission from the parent to use them in marketing.
